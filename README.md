# Knowledge Base Writing Repository

這是一個專為「知識庫文件寫作」設計的環境，整合了多個 Agent Skills 來提升寫作效率與品質。

## 目錄結構

- `docs/`: 存放正式的知識庫文件。
- `.agent/skills/`: 存放專屬的 Agent 技能指令（校對、結構優化、研究助理）。
- `templates/`: 提供標準化的 Markdown 寫作範本。

## 如何開始

1. 在 `docs/` 資料夾中建立新的 `.md` 檔案。
2. 您可以參考 `templates/standard_doc.md` 的格式。
3. 寫作過程中，可以隨時呼叫上述技能來協助您。
