# [KG-FRAMEWORK] 智人運算節點 (The Sapiens Computational Node)

## 1. Purpose (The Problem Space)

* **Goal:** 定義「文明計算圖」(Civilization Computing Graph, CCG) 中的最小運算單元。
* **Scope:** 任何在社會拓撲中運作的生物智人 (Homo Sapiens) 實例。
* **Abstraction:** 將複雜的神經生物動力學簡化為標準化的「輸入-處理-輸出」運算模型。
* **Core Function:** **熵壓縮 (Entropy Compression)**。節點充當「馬克士威妖 (Maxwell's Demon)」，將高熵的現實 (L0) 過濾為低熵的真理模型 (L7)，以最小化生存誤差。

## 2. Theoretical Basis (The Stack)

* **L0 Axioms:** 基於 [[KG-AXIOM] 文明計算圖總論].
* **Key Assumptions:**
  * *Assumption 1 (The Wear):* L0 (物理現實) 是熱力學磨損與資訊雜訊的來源。
  * *Assumption 2 (The Target):* L7 (物理定律) 是支配 L0 運作的不變結構。
  * *Assumption 3 (The Isomorphism):* 心理特徵 (Psychological Traits) 與神經運算超參數 (Neuro-computational Hyperparameters) 是同構的。

## 3. The Protocol (The Syntax)

> *智人節點是一個巢狀過濾器 (Nested Hierarchy of Filters)，負責將混沌轉化為秩序。*

### 3.1 Entities (The Layered Architecture)

節點由五個不同的地層組成，依據演化年代與修改能耗排列：

* **L1 Hardware (The Reactor):**

  * *Component:* 腦幹 (Brainstem), 基底核 (Basal Ganglia) & 杏仁核 (Amygdala/ACC)。
  * *Param:* **E/I (Signal Source)**, **A/O (Gain Control)**, **J/P (Stopping Rule)**。
  * *Role:* 生存訊號的即時累積與穩壓。針對物理威脅執行**硬切斷 (Hard Cutoff)**。
  * *Type:* **Immutable ROM**。在胚胎發生期 (Embryogenesis) 燒錄。
* **L2 Firmware (The Simulator):**

  * *Component:* 新皮質 (Neocortex) & 邊緣系統迴路 (Limbic Circuits)。
  * *Param:* **S/N (Topology)**。
  * *Role:* **空間建模 (Spatial Modeling)**。定義神經網絡的連接拓撲（解析度 vs 壓縮率）。
  * *Type:* **WORM (Write Once, Read Many)**。在兒童期 (0-12歲) 透過神經修剪固化。
* **L2.5 Chemical State (The Modulator):**

  * *Component:* 神經遞質 (Neurotransmitters: DA, 5-HT, NE)。
  * *Role:* 動態調整**操作點 (Operating Point)**。例如：壓力 (High NE)導致隧道視野 (S-mode)。
  * *Type:* **Volatile RAM**。秒級至小時級的動態存儲。
* **L3 Software (The Optimizer):**

  * *Component:* 背外側前額葉 (DLPFC)。
  * *Param:* **T/F (Loss Function)**。
  * *Role:* 邏輯/價值仲裁。最小化**邏輯矛盾 (Type T)** 或 **社交摩擦 (Type F)**。
  * *Type:* **Programmable Flash**。可透過教育與 IDE 進行修改。
* **L4 Interface (The Mask):**

  * *Component:* 鏡像神經元 (Mirror Neurons) & 社交迴路。
  * *Param:* **H/C (Coupling Coefficient $\kappa$)**。
  * *Role:* 動態邊界控制。調節與外部網絡的資訊滲透率。
  * *Type:* **Hot-Swappable Driver**。毫秒級的熱插拔適應。

### 3.2 Rules (Invariants)

* **Rule 1: Conservation of Compute (能耗階層定律):**
  * $E_{cost}(L1\_change) \gg E_{cost}(L3\_change)$。
  * 強行以軟體 (L3) 覆蓋硬體 (L1) 會導致 **熱應力崩潰 (Burnout)**。
* **Rule 2: Impedance Matching (阻抗匹配):**
  * 高效節點必須將其韌體拓撲 (S/N) 與輸入熵匹配。
  * *Mismatch A:* 敏感硬體 (O) + 原始輸入 (S) = **熱過載 (Overload/Anxiety)**。
  * *Mismatch B:* 魯棒硬體 (A) + 稀疏輸入 (N) = **熱寂 (Void/Boredom)**。
* **Rule 3: The Tri-Network Cycle (三網博弈循環):**
  * 節點在 **訓練 (DMN / Offline)**、**推論 (TPN / Online)** 與 **切換 (SN)** 之間振盪。
  * 創造力是由此循環管理的**相變 (Phase Transition)**。

### 3.3 State Space

* **Dimensions:** 由 **64型矩陣 (64-Type Matrix)** 定義的 6 個超參數。
* **Equilibrium:** **內應力 (Internal Stress)** 與 **外應力 (External Stress)** 最小化的狀態。

## 4. Methodology (The Algorithm)

* **Analysis Step 1 (Profiling):** 識別節點的 **硬體矩陣** (E/I, A/O, J/P)。這是「不可變約束」。
* **Analysis Step 2 (Debugging):** 檢查 **層級錯配 (Layer Mismatch)**。是否試圖在 N 型韌體上運行 S 型軟體？
* **Analysis Step 3 (Optimization):** 使用 **化學調節** (L2.5) 暫時移動操作點以適應特定任務（例如：提升 NE 以執行任務）。
* **Metrics:**
  * **$\Delta S_{int}$ (Internal Entropy):** 認知失調 (Cognitive Dissonance) 的測量。
  * **$\eta_{pred}$ (Prediction Efficiency):** L5 模型相對於 L0 現實的準確率。
