# L3: CASE (案例層)

**Defining Principles:** 特定實例、場景數據、決策信號

此層級存放模型在現實世界中的「執行實例」，分為三種子類型：

| Tag | 定位 | 目錄 |
|---|---|---|
| `[KG-CASE]` | **理論投射案例** — 由上至下，套用 KG 框架解析具體現象，沿用 L2 章節骨架 | `L3_CASE/` |
| `[KG-ESSAY]` | **概念科普散文** — 故事先行，以日常情境帶入 KG 概念，語氣親切流動 | `L3_CASE/essays/` |
| `[KG-ARTICLE]` | **嚴謹技術文章** — 論點導向，有明確主張與系統化論據，可附參考文獻 | `L3_CASE/articles/` |

> **Frontmatter `type` 欄位：** `case` / `essay` / `article`
