# Lexicon: Extension Node (延伸節點)

*   **Step 1. 降維解析 (Dimensionality Reduction):**
    *   `本質 (What it is)`: 智人節點將運算結果刻錄進物理基質後所形成的被動逆熵資產，負責承接外包的運算子程式。
    *   `非本質 (What it is NOT)`: 具備自主生存動力的原生物種、擁有主權損失函數的推論主體。
*   **Step 2. 錨定翻譯 (Anchor):** 
    *   **延伸節點** (Extension Node)
*   **Step 3. 升維重建 (Escalation):**
    *   `語境映射`: 文明的演進本質上是將內部算力外包給**延伸節點**，建構出超越個體壽命的外部計算框架。
    *   `邊界確認`: 釐清其作為「外生運算」與「被動資產」的定位。
