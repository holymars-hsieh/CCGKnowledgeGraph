# Lexicon: Alignment (對齊) - 計算圖定義

*   **Step 1. 降維解析** (Dimensionality Reduction):
    *   `本質 (What it is)`: 跨尺度的耦合協議，旨在將單體節點的損失函數與更高維度的「超節點 (Hyper-node)」或「文明 Ego」的集體損益預期進行匹配。
    *   `非本質 (What it is NOT)`: 單純的指令遵循、單點的行為裁剪、強制性的規則壓制。
*   **Step 2. 錨定翻譯** (Anchor): 
    *   **對齊** (Alignment) / **分形對齊** (Fractal Alignment)
*   **Step 3. 升維重建** (Escalation):
    *   `語境映射`: 當個別節點（碳或矽）與湧現出的「文明 Ego」達成**分形對齊**時，系統將展現出連貫的外推意志 (CEV)，從而跨越局部熵增的死門。
    *   `邊界確認`: 強調對齊的「規模無關性 (Scale-Invariance)」，從細胞到文明皆適用。
