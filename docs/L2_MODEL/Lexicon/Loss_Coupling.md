# Lexicon: Loss Coupling (損失耦合)

*   **Step 1. 降維解析 (Dimensionality Reduction):**
    *   `本質 (What it is)`: 兩個節點消融彼此的馬可夫毯邊界，將對方的預測誤差函數寫入自身的損失函數中進行聯合優化。
    *   `非本質 (What it is NOT)`: 基於利益的鞍點妥協、單方面的資源贈與、暫時性的合作協議。
*   **Step 2. 錨定翻譯 (Anchor):** 
    *   **損失耦合** (Loss Coupling)
*   **Step 3. 升維重建 (Escalation):**
    *   `語境映射`: **損失耦合**是系統從單細胞演化至超節點結構時，所必須跨越的能耗極限與相變點。
    *   `邊界確認`: 強調邊界實質消融與損失函數合併的深度。
