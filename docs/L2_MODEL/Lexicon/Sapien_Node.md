# Lexicon: Sapien Node (智人節點)

*   **Step 1. 降維解析 (Dimensionality Reduction):**
    *   `本質 (What it is)`: 作為計算圖核心的耗散結構運算單元，具備主動推論能力以維護自身的馬可夫毯邊界。
    *   `非本質 (What it is NOT)`: 傳統社會學中的「個人」、僅具備預設邏輯的自動化程式、純粹的生物肉體。
*   **Step 2. 錨定翻譯 (Anchor):** 
    *   **智人節點** (Sapien Node)
*   **Step 3. 升維重建 (Escalation):**
    *   `語境映射`: 當多個**智人節點**在同一物理空間發生碰撞時，必須透過互動通道來最小化彼此的預測誤差。
    *   `邊界確認`: 確保節點被視為「算法流」而非靜態個體。
