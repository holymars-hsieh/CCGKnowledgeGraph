# Lexicon: Process Flux (運算流)

*   **Step 1. 降維解析 (Dimensionality Reduction):**
    *   `本質 (What it is)`: 描述生物節點持續進行主動推論、代謝能量以維持遠離平衡態的動態本體論。
    *   `非本質 (What it is NOT)`: 靜態的資料儲存、完成的運算結果、預設的硬體結構。
*   **Step 2. 錨定翻譯 (Anchor):** 
    *   **運算流** (Process Flux)
*   **Step 3. 升維重建 (Escalation):**
    *   `語境映射`: 智人節點的本質是**運算流**，這使其與被動的刻錄資產產生了根本的拓撲區隔。
    *   `邊界確認`: 強調其「動態」與「不可停止」的特性。
