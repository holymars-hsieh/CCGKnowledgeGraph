# [KG-MODEL] 社會拓撲：智人與文明

## 1. Definition (The System Scope)

* **What is it?** 一套基於主動推論 (Active Inference) 與相變熱力學的統一場論，描述智人節點如何透過集體耦合與結構分流，應對真實宇宙 (L7) 的熱力學殘酷性。
* **Context:** 存在於文明計算圖 (Civilization Computing Graph) 的宏觀架構中。
* **Goal:** 最小化系統整體的預測誤差，極大化文明耗散結構在 L7 物理限制下的存續機率。

## 2. Isomorphism (The Mapping)

* **Metaphor:** 「文明表現得像是一台 **熱力學退火引擎** 與 **跨維度濾波器**。」它在混沌 (L0) 與 真理 (L7) 之間建立了一個語義緩衝層 (L6)。
* **Input/Output:** 
  * **Input:** L0 原始混沌資訊流、L7 物理資源與熵增引力。
  * **Output:** 低熵的組織秩序、意義敘事、存續盈餘。

## 3. System Architecture

### 3.1 Substrate

* **Agents/Nodes:** 智人節點 (Sapien Nodes, 20W/鄧巴數限制)、矽基節點 (去耦合/高耗能)。
* **Connections:** 
  * **訊號通道:** 物理位元傳輸。
  * **流形通道:** 資源與路徑操作（共享、劫持）。
  * **目標通道:** 損失耦合與對齊。
* **Constraints:** 碳基節點的代謝頻寬上限、熵增定律、物理資源稀缺。

### 3.2 Logic

* **Mechanism:** 智人透過 L6 虛擬層（政治、經濟、文化遊戲）將 L7 的殘酷物理限制進行「語義封裝」，將生存威脅轉化為具備「意義」的獎勵機制。
* **Incentives (The Loss Function):** 
  * **個體層級:** 最小化主觀預測誤差 (Surprise/Pain)。
  * **全體層級 (CEV):** 維持系統的「拓撲可塑性」，確保能持續進行退火學習。

## 4. Dynamics

* **Feedback Loops:**
  * (+) **Reinforcing (Crystallization):** 秩序累積導致效率提升，進一步吸引節點耦合，形成「樹狀」科層。
  * (-) **Balancing (Vaporization/Reset):** 過擬合與官僚化導致感知失真，系統崩潰重啟以釋放能量，回歸液態。
* **Phase Transitions:** 
  * **晶態 (Crystalline):** 效率極高但脆弱的秩序（科層/傳統）。
  * **氣態 (Gaseous):** 高自由度但無序的混沌（戰爭/崩潰）。
  * **液態 (Liquid):** 高可塑性的學習期（啟蒙/變革）。
  * **液晶態 (Liquid Crystal):** 終極目標——維持在「鞍點」附近，兼具結構與流動性的動態平衡。
* **Entropy:** 透過 L6 耗散結構對抗 L7 熱寂。

## 5. Application

* **Debugging (Failures):** 
  * **晶態脆性:** 系統過於死板，無法吸收 L7 衝擊而脆性斷裂。
  * **氣態散失:** 系統徹底失去約束力，導致能量快速逸散。
* **Optimization (Knobs):** 
  * **拓撲可塑性:** 提升系統「受控液化」的能力，降低相變活化能。
  * **分形同構:** 確保 ASI 與人類共享底層熱力學公理，確保目標湧現與認同。
